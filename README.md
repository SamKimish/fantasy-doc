# Fantasy Doc

A mobile-friendly web app that shows which of your starting fantasy NFL players are injured.
Enter your Sleeper username and it checks every non-best-ball NFL league you're in.

No backend, no build step: it's a single static `index.html` that calls the public Sleeper API.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy

Works on any static host (GitHub Pages, Cloudflare Pages, etc.).
